# Supplier, Brand, and Category Suggestions

## Supplier

In Products & Stock-In, click Supplier and start typing the beginning of the supplier name.
The dropdown suggests matching existing suppliers and completes the text.

- Arrow keys: move through suggestions
- Enter: select
- `+ Supplier`: create a supplier that is not found

The invoice can only be posted with an existing selected supplier, preventing accidental duplicate names.

## Brand and Category

In New Product or Edit Product, start typing in Brand or Category. Existing values are suggested immediately.

- Arrow keys: move through suggestions
- Enter: select
- `+` button: add a missing brand or category

The controls remain normal WinForms ComboBoxes and are editable in View Designer.

## Database

No database or SQL update is required.
