# Scanner and Printer Settings

## Product Stock-In search and scanning

Use the single **Search / Scan** box.

- Typing filters by description, code, barcode, brand, and category.
- An exact barcode or product code followed by Enter or Tab opens a quantity popup.
- Type the quantity and press Enter to add the product.
- When several typed results remain, choose from the filtered grid.
- After adding, the same Search / Scan box clears and receives focus again.

There is no separate Scan Barcode box and no quantity-first field.
