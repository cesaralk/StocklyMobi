# Products & Stock-In — Unified Search / Scan

## One input

Use the single Search / Scan box for manual search and the physical barcode
scanner.

## Manual search

Type a complete description, several words, product code, barcode, brand, or
category. The product grid filters while focus stays inside Search / Scan.

- Down Arrow moves to the filtered grid.
- Enter with one result opens the quantity window.
- Enter on a selected row opens the quantity window.
- Escape clears the search.
- Ctrl+F, Ctrl+B, or F3 focuses Search / Scan.

## Scanner

An exact barcode or product code followed by Enter or Tab opens the quantity
window. Type the quantity and press Enter to add the line.

After a successful add, Search / Scan clears and receives focus again.

No separate scanner or quantity-first box is used.
