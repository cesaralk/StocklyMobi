# StocklyMobi Visual Designer Guide

All newer features now use the standard WinForms structure:

- `FormName.cs` — logic and event handlers
- `FormName.Designer.cs` — controls and layout
- `FormName.resx` — resources

Open a form in Visual Studio with **Shift+F7**. Use **F7** for code and **F4** for Properties.

Converted pages:

- Products & Stock-In
- Mobile Fixing
- Deliver Fixed Phone
- Services Management
- Service Picker
- Invoice History
- Receipt Search
- Daily Profit
- Discount History
- Transaction Discount
- New Product
- Validity Retake
- Text Entry
- Quantity Entry

Database-driven rows and service cards appear only at runtime, but their containers, grids, columns, search fields, and action buttons are editable in Designer.

No database script is required for this conversion.
